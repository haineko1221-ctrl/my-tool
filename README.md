## 🍚 まいにちごはん

高齢者向けの食事記録・AI分析システム

### コンセプト

料理の写真を送るだけで、AIが食事内容をざっくり分析し、毎日の食事を気にかけるきっかけを作るシステム。

**「食べる＝生きる」**

正確なカロリー計算や医療的な食事指導ではなく、食べることを楽しむことを目的としています。

### 主な機能（MVP）

- 📷 写真アップロードで簡単記録
- 🤖 AIによる料理・食材認識
- 💬 優しく前向きな「今日のひとこと」
- 🥗 食事バランスの簡易判定
- 🌅 明日の食事提案
- 📊 連続記録・チェック履歴

### ドキュメント

詳細な仕様書は [`mainichi-gohan/docs/spec.md`](./mainichi-gohan/docs/spec.md) を参照してください。
