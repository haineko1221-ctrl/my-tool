# 🗺️ ロードマップナビ

顧客フォロー・ロードマップ管理システム

## 📋 概要

顧客・見込み客など、一人ひとりに対して決められたフォローアップ手順（ロードマップ）を登録し、登録日や前ステップの完了日を基準に、次に行うべきアクションを自動的に表示・通知するシステムです。

### コアコンセプト

**「顧客ごとの次の一手を忘れない」**

単なるカレンダーではなく、「Aさんは現在ロードマップのどの段階にいて、次に何をすべきなのか」を管理することを目的としています。

## ✨ 主な機能（MVP）

### 📊 ダッシュボード
- 今日やるべきフォロー一覧
- 遅れているフォロー一覧
- ワンクリックでステップ完了

### 👥 顧客管理
- 顧客登録・一覧表示
- 顧客ごとのロードマップ進捗可視化（🟢🔵⚪）
- 現在のステップ表示
- 顧客削除

### 🗺️ ロードマップ管理
- ロードマップテンプレート作成
- 複数ステップの設定
- **ルート再計算機能**
  - 登録日基準: 顧客登録日から○日後
  - 前ステップ完了基準: 前のステップ完了から○日後（動的再計算）

### 🔄 ルート再計算の仕組み

ステップ完了時に、以降のステップで「前ステップ完了基準」のものを自動的に再計算します。

**例:**
```
Step 1: Day 0 (登録日) → 8/21完了
Step 2: Day 2 (登録日基準) → 8/23予定
Step 3: 前ステップ+3日 (完了基準) → Step2完了(8/25)から3日後 → 8/28に自動更新
```

## 🛠️ 技術スタック

- **フロントエンド**: Next.js 16.3.2 (App Router) + TypeScript
- **スタイリング**: TailwindCSS 4.0
- **データ保存**: LocalStorage（MVP版）
- **状態管理**: React Hooks

## 🚀 セットアップ

### 1. 依存関係のインストール

```bash
npm install
```

### 2. 開発サーバーの起動

```bash
npm run dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開いてください。

### 3. サンプルデータ

初回アクセス時に、サンプルロードマップ「新規顧客フォロー」が自動生成されます。

## 🎯 使い方

### 1. ロードマップを作成

「🗺️ ロードマップ」→「+ ロードマップを作成」

- ロードマップ名を入力
- ステップを追加
- 各ステップの基準タイプを選択
  - **登録日基準**: 顧客登録日から○日後
  - **前ステップ完了基準**: 前のステップ完了から○日後

### 2. 顧客を登録

「👥 顧客一覧」→「+ 顧客を登録」

- 顧客名、登録日、ロードマップを選択
- 登録すると、自動的に全ステップの予定日が計算される

### 3. 今日のフォローを確認

「📊 ダッシュボード」

- 今日やるべきフォローが自動表示
- 「完了」ボタンでステップ完了
- ★完了すると、次以降のステップが自動再計算される★

### 4. 顧客の進捗を確認

「👥 顧客一覧」→ 顧客を選択

- ロードマップ全体の進捗を可視化
- 現在のステップを確認
- 各ステップの予定日・完了日を表示
