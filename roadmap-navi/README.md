# 🗺️ ロードマップナビ

顧客フォロー・ロードマップ管理システム

**本番URL:** https://my-tool-kwi3.vercel.app

## 📋 概要

顧客・見込み客など、一人ひとりに対して決められたフォローアップ手順（ロードマップ）を登録し、登録日や前ステップの完了日を基準に、次に行うべきアクションを自動的に表示・通知するシステムです。

### コアコンセプト

**「顧客ごとの次の一手を忘れない」**

単なるカレンダーではなく、「Aさんは現在ロードマップのどの段階にいて、次に何をすべきなのか」を管理することを目的としています。

## ✨ 主な機能（MVP）

### 📊 ダッシュボード
- **📅 月表示カレンダー**（日曜始まり）
  - 顧客ごとに色分け表示
  - ステータスアイコン（🟢完了 🔵予定 🔴遅延）
  - 日付クリックでタスク詳細表示
  - 前月・次月移動、今日ハイライト
- 今日やるべきフォロー一覧
- 遅れているフォロー一覧
- ワンクリックでステップ完了

### 👥 顧客管理
- 顧客登録・一覧表示
- 顧客ごとのロードマップ進捗可視化（🟢🔵⚪）
- 現在のステップ表示
- 顧客削除

### 🗺️ ロードマップ管理
- ロードマップテンプレート作成・**編集**・削除
- 複数ステップの設定
- **3つの基準タイプ**
  - **登録日基準**: 顧客登録日から○日後
  - **前ステップ完了基準**: 前のステップ完了から○日後（ルート再計算）
  - **毎年固定日付（年中行事）**: お正月、クリスマスなど毎年決まった日付
- **🔄 繰り返しステップ**: 完了すると自動的に次回が作成される（例: 3日ごとの生存確認）
- **🎌 年中行事**: 完了すると来年の同じ日付が自動作成

### 🔄 ルート再計算の仕組み

ステップ完了時に、以降のステップで「前ステップ完了基準」のものを自動的に再計算します。

**例:**
```
Step 1: Day 0 (登録日) → 8/21完了
Step 2: Day 2 (登録日基準) → 8/23予定
Step 3: 前ステップ+3日 (完了基準) → Step2完了(8/25)から3日後 → 8/28に自動更新
```

## 🛠️ 技術スタック

- **スタイリング**: TailwindCSS 4.0
- **データ保存**: LocalStorage（MVP版）

## 🎯 使い方

### 1. ロードマップを作成

「🗺️ ロードマップ」→「+ ロードマップを作成」

- ロードマップ名を入力
- ステップを追加
- 各ステップの基準タイプを選択
  - **登録日基準**: 顧客登録日から○日後
  - **前ステップ完了基準**: 前のステップ完了から○日後
  - **毎年固定日付（年中行事）**: 月と日を指定（例: 1月1日、12月25日）
- オプション: 🔄繰り返しステップにする（例: 3日ごと、7日ごと）

### 2. 顧客を登録

「👥 顧客一覧」→「+ 顧客を登録」

- 顧客名、登録日、ロードマップを選択
- 登録すると、自動的に全ステップの予定日が計算される

### 3. カレンダーで一目で確認

「📊 ダッシュボード」のカレンダー

- 月表示で全顧客のタスクを一覧
- 顧客ごとに色分け表示
- 日付をクリックするとその日のタスク詳細が表示される
- 🟢完了 🔵予定 🔴遅延 のアイコンでステータス確認

### 4. 今日のフォローを確認

「📊 ダッシュボード」

- 今日やるべきフォローが自動表示
- 「完了」ボタンでステップ完了
- ★完了すると、次以降のステップが自動再計算される★
- 繰り返しステップの場合、次回が自動作成される

### 5. 顧客の進捗を確認

「👥 顧客一覧」→ 顧客を選択

- ロードマップ全体の進捗を可視化
- 現在のステップを確認
- 各ステップの予定日・完了日を表示

### 6. ロードマップを編集

「🗺️ ロードマップ」→「編集」ボタン

- 既存のロードマップを編集可能
- ステップの追加・削除・変更
- 注意: 既存顧客の進捗には影響しない（新規登録顧客から適用）

## ⚠️ 既知の課題

### データ同期
- **現状**: LocalStorageを使用しているため、端末ごとにデータが独立
- **影響**: PC、スマホ、複数ユーザーでデータが紐づかない
- **解決策（検討中）**:
  - Googleスプレッドシートをデータベースとして利用（簡易）
  - Firebase/Supabaseでログイン機能追加（本格的）

### 遅延タスクの扱い
- **現状**: 予定日を過ぎても元の日付に表示されたまま（🔴遅延表示）
- **検討中の改善案**:
  - 自動延期: 毎日0時に未完了タスクを「今日」に移動
  - 手動延期: 「明日に延期」ボタンを追加
  - 表示調整: 遅延タスクを常に「今日」に表示

### ロードマップ編集の既存顧客への影響
- **現状**: ロードマップ編集は新規登録顧客のみ適用
- **検討中の改善案**:
  - 顧客ごとにロードマップを変更する機能
  - 編集時に「既存顧客にも適用」オプション
